06 / REINFORCEMENT LEARNING

Learning through
interaction.

A reinforcement learning case study using Pac-Man to explore Q-learning, state representation, exploration and tile coding.

RL / 01

Pac-Man AI

A model-free Q-learning agent that learns action values through interaction with the environment, using tile coding to represent the state space.

Q-LEARNING TILE CODING EXPLORATION AGENTS
THE PROBLEM

How does an agent learn what to do when the environment is constantly changing?

Pac-Man provides a compact environment for studying reinforcement learning. The agent observes the environment, represents its current state, selects an action, receives a reward and updates its knowledge based on the outcome.

Rather than manually defining the correct action for every situation, the agent learns which actions are valuable through repeated interaction.

01 STATE Environment representation
02 ACTION Up · Right · Down · Left
03 REWARD Positive and negative feedback
04 UPDATE Q-value learning
01
STATE REPRESENTATION

Tile coding

The state space is transformed into overlapping tile-based features. Instead of treating every possible environment configuration as an entirely unrelated state, tile coding provides a structured representation that allows similar states to share information.

02
VALUE LEARNING

Q-learning

For each state and available action, the agent estimates the expected future reward. These Q-values are progressively updated as the agent experiences different outcomes.

UP Q(s, up)
RIGHT Q(s, right)
DOWN Q(s, down)
LEFT Q(s, left)
03
DECISION MAKING

Exploration vs exploitation

The agent balances using actions that currently have high estimated value with exploring alternative actions. The exploration rate gradually decreases during learning.

ε-greedy → Explore ↔ Exploit
REWARD DESIGN

The environment teaches the agent through consequences.

+10 Point
-1 Empty space
-50 Wall
-100 Ghost
