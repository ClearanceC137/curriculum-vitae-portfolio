# Tshepiso Mahoko — AI Portfolio

A deliberately non-linear, recruiter-friendly CV website.

## What makes it different

- Interactive constellation-style home screen instead of a traditional CV layout.
- Sections behave like nodes in a portfolio map rather than a linear document.
- **Recruiter Lens** lets a visitor switch the emphasis between:
  - AI / ML Engineer
  - Data Scientist
  - Industrial AI
  - Software Engineer
- Keyboard shortcuts `1–6` jump between views.
- No framework or build step required — plain HTML, CSS and JavaScript.
- Designed to deploy directly to GitHub Pages.

## Files

- `index.html` — page structure and content
- `styles.css` — visual system and responsive layout
- `script.js` — navigation, recruiter lens, role selector and interactions

## GitHub Pages

1. Create a repository for the website.
2. Upload these files to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch**.
4. Select the branch containing the files and `/root`.
5. Open the generated GitHub Pages URL.

## Updating the portfolio

Most content is intentionally kept in `index.html`, so it is easy to update projects, roles, education and contact details without a framework.
